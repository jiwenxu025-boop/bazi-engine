隐私政策

最后更新：2026-05-25

1. 我们收集的信息

本服务收集您主动提供的出生时间（年/月/日/时）和性别，用于八字排盘计算。姓名字段为可选，可使用化名。

我们不要求提供真实姓名、身份证号、手机号、地址或其他个人身份信息。

2. 信息的使用

出生时间和性别仅用于八字排盘计算，不做其他用途。AI 追问功能的对话内容仅在当前会话期间保留，不持久化存储。

3. 信息的存储

排盘计算在服务器端完成，计算结果缓存于内存中，服务重启后清空。我们不将排盘数据写入数据库。

激活码与追问次数记录在服务器端 JSON 文件中，不关联个人身份信息。

4. Cookie 与本地存储

前端使用 localStorage 存储：主题偏好、激活码、免责声明确认状态。不包含个人身份信息。

5. 第三方服务

AI 追问功能通过 DeepSeek API 实现，您的提问内容会发送至 DeepSeek 服务器。DeepSeek 的隐私政策见其官网。

6. 数据删除

如需删除与您相关的数据，请联系服务提供方。由于我们不关联个人身份，您需提供使用时间段的描述以协助定位。

7. 免责声明

本服务仅供文化娱乐参考，不替代专业医疗、法律、心理咨询。AI 生成内容不代表服务提供方立场。

8. 联系方式

隐私相关问题请通过微信联系服务提供方。

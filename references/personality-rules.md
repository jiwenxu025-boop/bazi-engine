# 第一部分：性格分析

## 1.1 日干核心性格（来源：《滴天髓》原文 + 《穷通宝鉴》实物意象）

### 甲木 — 栋梁之木，首领型
- **《滴天髓》原文**: "甲木参天，脱胎要火。春不容金，秋不容土。火炽乘龙，水宕骑虎。地润天和，植立千古。"
- **核心性格**: 正直刚强，上进心强，仁慈有责任感，领袖风范
- **负面**: 固执不灵活，强行干涉他人，自负好大
- **《穷通宝鉴》实物**: 参天大树/栋梁之材
- **成材关键**: 甲不离庚(需庚金砍凿方成栋梁)
- **最佳组合**: 甲 + 庚 + 丁（甲引丁火→丁锻庚金→庚劈甲木）
- **五行五德(木)**: 主仁，恻隐之心，恬静清高，人物清秀。太过则折，执拗性偏；不及则少仁，心生妒意

### 乙木 — 藤萝花草，依附型
- **《滴天髓》原文**: "乙木虽柔，刲羊解牛。怀丁抱丙，跨凤乘猴。虚湿之地，骑马亦忧。藤萝系甲，可春可秋。"
- **核心性格**: 温和柔巧，灵活变通，适应性强，韧性十足，善于借力
- **负面**: 敏感多疑，三心二意，缺乏主见，有心机
- **《穷通宝鉴》实物**: 藤萝/花草/禾苗
- **生存策略**: "藤萝系甲"——依附甲木(强者/贵人)方得长青
- **五行五德(木)**: 同甲木，偏柔

### 丙火 — 太阳之火，领袖型
- **《滴天髓》原文**: "丙火猛烈，欺霜侮雪。能煅庚金，逢辛反怯。土众成慈，水猖显节。虎马犬乡，甲木若来，必当焚灭。"
- **核心性格**: 热情外扬，光明磊落，不畏强权，急躁骄傲
- **负面**: 性急莽撞，不擅收敛，过于张扬
- **《穷通宝鉴》实物**: 太阳之火
- **关键**: "逢辛反怯"——丙辛合化水，英雄难过美人关
- **五行五德(火)**: 主礼，辞让恭敬，言语辞急，意速心焦。太过则性躁；不及则奸巧妒毒

### 丁火 — 灯烛之光，内秀型
- **《滴天髓》原文**: "丁火柔中，内性昭融。抱乙而孝，合壬而忠。旺而不烈，衰而不穷。如有嫡母，可秋可冬。"
- **核心性格**: 敏锐细腻，外柔内刚，忠诚持久，文明之象
- **负面**: 多愁善感，过于细腻
- **《穷通宝鉴》实物**: 灯烛/星光/炉火
- **关键**: "旺而不烈，衰而不穷"——绵延不绝，持久力强
- **五行五德(火)**: 同丙火，偏柔

### 戊土 — 城墙高山，稳重型
- **《滴天髓》原文**: "戊土固重，既中且正。静翕动辟，万物司命。水润物生，火燥物病。若在艮坤，怕冲宜静。"
- **核心性格**: 厚重信实，沉稳可靠，诚实守信，如山可靠
- **负面**: 固执保守，缺乏灵活性，过于沉稳
- **《穷通宝鉴》实物**: 城墙/堤岸/高山
- **关键**: 怕冲(寅申冲/辰戌冲)，宜静不宜动
- **五行五德(土)**: 主信，敦厚至诚，度量宽厚。太过则愚朴固执；不及则朴实执拗

### 己土 — 田园湿土，包容型
- **《滴天髓》原文**: "己土卑湿，中正蓄藏。不愁木盛，不畏水狂。火少火晦，金多金光。若要物旺，宜助宜帮。"
- **核心性格**: 包容力强，善于调和，恋家重情，天生的和事佬
- **负面**: 多虑阴湿，易纠结
- **《穷通宝鉴》实物**: 田园/湿地/沃土
- **关键**: 不怕木克、不怕水多，能晦火润金
- **五行五德(土)**: 同戊土，偏柔

### 庚金 — 刀斧顽铁，刚硬型
- **《滴天髓》原文**: "庚金带煞，刚健为最。得水而清，得火而锐。土润则生，土干则脆。能赢甲兄，输于乙妹。"
- **核心性格**: 果断刚硬，执行力强，讲义气，原则性强不妥协
- **负面**: 不善变通，易刚直伤人，急躁
- **《穷通宝鉴》实物**: 顽铁/刀剑/斧钺
- **成材关键**: 庚不离丁(需丁火锻炼方成利器)
- **最佳组合**: 庚 + 丁 + 甲（甲生丁→丁锻庚→庚劈甲）
- **五行五德(金)**: 主义，仗义疏财，刚毅有决。太过则好斗贪欲；不及则悭吝少果决

### 辛金 — 珠玉首饰，精致型
- **《滴天髓》原文**: "辛金软弱，温润而清。畏土之叠，乐水之盈。能扶社稷，能救生灵。热则喜母，寒则喜丁。"
- **核心性格**: 精致锐利，追求完美，细腻有审美，商业头脑
- **负面**: 多愁善感，娇气，过于挑剔
- **《穷通宝鉴》实物**: 珠玉/首饰/金银
- **关键**: 怕土多被埋(才华不得施展)，喜水淘洗(显其光泽)
- **五行五德(金)**: 同庚金，偏柔

### 壬水 — 江河大海，豪放型
- **《滴天髓》原文**: "壬水通河，能泄金气。刚中之德，周流不滞。通根透癸，冲天奔地。化则有情，从则相济。"
- **核心性格**: 智谋流动，聪明灵活，志向远大，行动力强，善交际豪放
- **负面**: 过旺则如洪水泛滥，难以约束
- **《穷通宝鉴》实物**: 江河/湖海/瀑布
- **关键**: 弱时从火土则水火既济(吉)，旺时需木疏
- **五行五德(水)**: 主智，足智多谋，机关深远。太过则诡诈狠戾；不及则胆小无谋

### 癸水 — 雨露溪流，内敛型
- **《滴天髓》原文**: "癸水至弱，达于天津。得龙而运，功化斯神。不愁火土，不论庚辛。合戊见火，化象斯真。"
- **核心性格**: 内敛深沉，聪慧敏感，观察入微，心思缜密，适应力强
- **负面**: 多心眼，城府较深
- **《穷通宝鉴》实物**: 雨露/雾气/溪流/泉水
- **关键**: "至阴至柔，渗透力极强"；遇戊土合化火则被降服
- **五行五德(水)**: 同壬水，偏柔

# 第二部分：家境分析

## 2.1 宫位定位（来源：《珞琭子三命消息赋》+《三命通会》）

```
年柱 = 祖上宫（祖父母、祖先根基）→ 1-15岁
月柱 = 父母宫（父母、兄弟）→ 16-30岁
日柱 = 自身宫 + 夫妻宫 → 31-45岁
时柱 = 子女宫 → 46岁以后
```

## 2.2 父母星定位（来源：《千里命稿》+《渊海子平》）

| 六亲 | 男命 | 女命 |
|------|------|------|
| **父亲** | 偏财 | 正财 |
| **母亲** | 正印 | 偏印 |

## 2.3 家境判断规则（来源：《三命通会》原文）

### 规则一：年月财官法（核心）
> 《三命通会·看命口诀》："年月上有财官，必生富贵之家，祖父根基，少年便行官禄运，多是幼年拜命，早发功名。年月无财官，日时有之，则是自己成立。"

| 条件 | 出身推断 |
|------|---------|
| 年柱或月柱有财星或官星（透干或本气） | 出身富贵，祖业丰厚 |
| 年月无财官，日时才有 | 白手起家，靠自己成立 |
| 年月无财官 + 幼年大运不好 | 出身卑微，破祖伤父 |

### 规则二：财官旺衰法
> 《络绎赋》："财官月旺，得父资财。"

| 条件 | 推断 |
|------|------|
| 月令财星或官星旺相 | 得父亲财产庇荫，家底厚 |
| 日主通月令之气 | "日通月气，得祖安身"——有祖业可依 |
| 年干有日主之正官 | "福气最厚" |
| 年干有日主之七杀 | "终身不可除去"——祖上有遗留麻烦 |

### 规则三：财印状态法（看父母关系）
> 《精微论》+ 盲派口诀

| 条件 | 推断 |
|------|------|
| 财星受冲克严重 | 父缘薄，或父亲运势差 |
| 印星受冲克严重 | 母体弱，或母子缘浅 |
| 财破印（财星克印星） | 父母感情不佳，或离异 |
| 年柱被月柱冲 | "离祖成家"——不得祖业，外出自立 |

### 规则四：凶星在年月（来源：《巫咸撮要》+《络绎赋》）

| 条件 | 推断 |
|------|------|
| 年月见伤官、劫财 | 生于贫贱之家，或为庶出 |
| 年上伤官 | 父母不全（一方早逝或分离） |
| 偏印在年柱（枭居祖位） | 破祖之基，祖业败落 |
| 年柱比劫重重 | 祖业被分薄，父母经济压力大 |
| 年月见空亡 | 祖上根基虚浮，家世不显 |

### 规则五：日主强弱调节（来源：《继善篇》+《三命通会》）

| 条件 | 推断 |
|------|------|
| 身强 + 年月有财官 | 出身确实富贵，且能承受 |
| 身弱 + 年月有财官 | 出身表面还可以，但自身无力继承，"纵遇财官为寒士" |
| 身强 + 年月无财官 | 出身普通但有本事白手起家 |
| 身弱 + 年月无财官 | 出身普通且发展较慢 |

## 2.4 家境分析总流程

```
输入: 八字四柱 + 日主旺衰 + 大运
                    ↓
Step 1: 宫位定位 → 年柱(祖上) 月柱(父母) 日柱(自身)
Step 2: 查年月财官 → 年月有无财星/官星透干或本气？
Step 3: 查父母星状态 → 财星(父) 印星(母) 是否受冲克？
Step 4: 查凶星年月 → 伤官/劫财/偏印/比劫是否在年柱月柱？
Step 5: 身强弱调节 → 身强能担?身弱难承?
Step 6: 生成家境描述
```

### 家境描述输出格式

**家境等级**（五档）：

| 等级 | 条件组合 |
|------|---------|
| **A · 家境优越** | 年月财官旺相 + 日通月气 + 无凶星破格 + 身强能担 |
| **B · 家境良好** | 年月有财官 + 无严重冲克 + 身强或通月令 |
| **C · 家境普通** | 年月无财官，日时有 / 年月有财官但身弱难担 |
| **D · 家境清贫** | 年月无财官 + 年月有伤官劫财 + 幼行坏运 |
| **E · 家道中落** | 年有财官但被冲克严重 / 枭居祖位 / 年冲月令 |

**父母状况**：

| 类型 | 条件 |
|------|------|
| 双全有助 | 财印不受冲克，父母宫旺相 |
| 父缘薄 | 财星受冲克 |
| 母缘薄 | 印星受冲克 |
| 父母不和 | 财破印(财克印) |
| 父母不全(一方早逝/分离) | 年上伤官 / 财或印被冲克极严重 |

**继承情况**：

| 类型 | 条件 |
|------|------|
| 得祖业 | 日通月气 + 年月为用神 |
| 白手起家 | 年月无财官 + 日时有财官 |
| 离祖成家 | 年冲月令 / 年月驿马重重 |
| 破祖自立 | 枭居祖位 / 年月伤官劫财 |

# 第三部分：实战校准（案例 A 徐继文反馈）

> 校准日期: 2026-05-24。以下规则基于案例 A 的实际家境和性格反馈修正，标记了"校准前"和"校准后"的差异。

## 3.1 天干地支分论原则

**校准前**：判断家境时混用天干和地支，不区分表里。

**校准后**：天干和地支严格分工——

| 层面 | 范围 | 含义 |
|------|------|------|
| **天干（外象）** | 透干之十神 | 外在表现、别人看得到的样子、"门面" |
| **地支（内情）** | 藏干+本气+相互作用 | 实际状况、家底、内部矛盾 |

**家境判定规则**：
- 年月天干喜用 + 年月地支也喜用 → A/B 级家境
- 年月天干喜用 + 年月地支忌神 → **表面体面，实际普通**，不高于 C 级
- 案例 A 验证：年干丁（喜用）+ 年支亥（忌神）、月干戊（喜用）+ 月支申（忌神）→ 实际家境 C+，表面还行

## 3.2 感情主动性判定

**校准前**：只看日干和十神判断主动/被动。

**校准后**：关键看是否有**正财或正官合日主**——

| 条件 | 感情模式 |
|------|---------|
| 正财合日主（男命）| 偏被动，被选择，等对方推进。正财为喜→遇到的对象质量好 |
| 正官合日主（女命）| 偏被动，被追求，等对方靠近 |
| 无合 | 看日干和七杀/食伤旺衰判断主动性 |
| 七杀旺 | 在事业/学业等领域果断主动，但**不自动延伸到感情领域** |

**案例 A 验证**：壬水日主，年干丁（正财）合壬（丁壬合），2023 恋爱完全被动，女方主动推进。七杀旺在月干（事业/学业果断），但在感情领域不体现主动性。

## 3.3 财星合日主的经济含义

**校准前**：财星合日主（丁壬合）仅判断财运好坏。

**校准后**：分两个维度——

| 维度 | 正财合日主的含义 |
|------|-----------------|
| **家境** | ≠家里很有钱。只表示家庭在命主身上的投入意愿强 |
| **命主经济** | 家里愿意给，命主本人生活不缺钱 |

**案例 A 验证**：丁（年干正财）合壬（日主）。家境实际 C+，但命主从小不缺零花钱，家里在命主的教育和生活上不吝啬投入。

## 3.4 年支比肩 + 偏财不显 = 父亲财务问题

**校准前**：年支比肩仅判断"祖业被分薄"。

**校准后**：年支比肩 + 偏财不显（男命父星不显）→ 指向父亲的消费/财务问题——

| 组合 | 象 | 含义 |
|------|-----|------|
| 年支藏比肩 | 比肩夺财 | 父亲花钱无度 |
| 偏财不显（男命） | 父缘薄、父不在正位 | 父亲不是传统榜样 |
| 年支为忌神 | 父之习性有负面影响 | 消耗家运 |
| 三者叠加 | — | 父亲偏好娱乐应酬、赌博等不良消费习惯 |

**案例 A 验证**：年支亥藏壬（比肩）+ 偏财丙火不显 + 年支亥为水（忌神）→ 父亲偏好娱乐应酬和赌博，对家庭经济有负面消耗。

## 3.5 相害关系的具体化

**校准前**：相害关系只说"可能有矛盾"，不指定具体人。

**校准后**：相害必须落实到具体六亲——

| 相害位置 | 涉及宫位 | 判断 |
|----------|---------|------|
| 年支 vs 月支 | 祖辈宫 vs 父母宫 | 父亲/母亲与祖辈关系不和 |
| 月支 vs 日支 | 父母宫 vs 夫妻宫 | 父母与配偶关系紧张（婆媳/岳婿） |
| 日支 vs 时支 | 夫妻宫 vs 子女宫 | 配偶与子女关系问题 |

**案例 A 验证**：亥（年支）申（月支）相害 → 父亲与祖辈关系不好。

## 3.6 十神在不同领域的分工原则（新增）

**一个十神不可能在所有人生领域都体现同一种特质。**

| 十神 | 事业/学业领域 | 感情领域 | 内心/情绪领域 |
|------|-------------|---------|-------------|
| **七杀旺** | 果断敢为，魄力强 | 未必主动（感情由财官合决定） | 抗压恢复快 |
| **正财合身** | 务实现实 | 被动接受，等对方推进 | 重视物质安全感 |
| **偏印格** | 思维独特偏门 | — | 外表社交自如，内心孤僻疏离 |

**案例 A 验证**：七杀旺+事业领域果断（高考敢离家远行，分手快刀斩乱麻），但在感情领域因丁壬合而被动。偏印格内心孤僻（外表善交但内心保持距离）。

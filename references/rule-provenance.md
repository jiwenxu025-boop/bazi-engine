# 规则来源与准入

本文件定义引擎规则的来源等级。任何新增规则必须标注其等级，不得把工程假设、现代流派或案例观察表述为古籍原文。

## 来源等级

| 标记 | 含义 | 使用边界 |
|------|------|----------|
| `古籍摘要` | 已记录书名或口诀，但仍可能是释义 | 不当作逐字原文；保留条件与版本差异 |
| `古籍推导` | 由多条传统规则组合出的工程判断 | 必须展示推导条件，不能写成原书结论 |
| `现代流派` | 近现代教材、流派或作者的方法 | 明示流派，不与古籍混写 |
| `工程启发式` | 为稳定输出设计的阈值、权重或评分 | 不用于宣称命理定论；可替换、可测试 |
| `案例观察` | 用户反馈、公开命例或校准记录 | 不直接进入通用规则；仅用于回归观测 |

## 当前模块

| 模块 | 主来源等级 | 约束 |
|------|------------|------|
| 四柱与节气 | 工程计算 | 以节气、日柱公式和早晚子时策略计算；必须有边界测试 |
| 干支关系 | 古籍推导 | 合、会、冲、刑、害先记录关系；化气与成局必须另验条件 |
| 格局与用神 | 古籍推导 + 工程启发式 | 强弱分数、阈值和从格门槛不是古籍原文 |
| 调候 | 古籍摘要 | 仅作独立观察，不以“废局”覆盖格局或强弱 |
| 神煞与纳音 | 古籍摘要 | 只作辅助参考；不得单独推导疾病、祖业、富贵或具体人生事件 |
| 流年事件 | 工程启发式 | 输出为文化参考，不作确定事件、医疗、寿命或他人行为断言 |
| 校准数据 | 案例观察 | 不参与 RAG 的古籍证据，不以 `N/M` 直接升级规则 |

## 准入检查

1. 写明来源等级、可核对出处或明确标为工程假设。
2. 列出必要条件、反条件和至少一个不应触发的反例。
3. 规则改动通过单元测试、全量回归和校准观测后才能启用。
4. 缺少证据时，输出“候选”或不输出，不能用确定性措辞补足。

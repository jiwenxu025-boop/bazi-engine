## 一、干支体象（《渊海子平》十干体象 + 十二支咏）

## 二、大运重地支 / 流年重天干

### 经典出处

> 《三命通会》：「凡行运在干，兼用地支之神；在支，则弃天干之物。盖大运重地支，故有行南方、东方、西方、北方之辨。」

### 规则体系

| 维度 | 大运 | 流年 |
|------|------|------|
| 重心 | **地支为体**，定十年吉凶本质 | **天干为用**，定当年事件主题 |
| 权重 | 60%（大运好六分好） | 40%（流年只占四成） |
| 分工 | 天干管前5年表象，地支管后5年实质 | 天干显外事，地支隐内变 |
| 判断优先级 | 先看地支是否助喜用 | 先看天干十神类别定性 |

### 实战运用

1. 大运地支助喜用 = 十年根基好，流年凶为"凶中藏吉"
2. 大运地支助忌神 = 十年根基差，流年吉为"吉中藏凶"
3. 大运天干生地支 → 前五年表象引导后五年实质
4. 大运与流年干支互动：大运吉 + 流年凶 = 凶中藏吉

### 盲派补充

> 「大运天干管五年，运支藏干分别管；大运地支化成干，生克制化有灵验。」

## 三、流年干支分论

### 干支力量分配（按干支关系）

| 干支关系 | 力量侧重 | 示例 |
|---------|---------|------|
| **干支一气** | 力量最强，同心同力 | 丙午、庚申、戊戌 |
| **天干生地支** | 侧重地支 | 庚子（金生水→地支增力） |
| **地支生天干** | 侧重天干 | 丙午（火助火→天干增力） |
| **盖头**（天干克地支） | 天干约60% | 甲辰（木克土→天干主导） |
| **截脚**（地支克天干） | 地支约60% | 甲申（金克木→地支主导） |

### 流年应期定位

- 流年天干事件→天干所在流月最旺时兑现
- 流年地支事件→地支所在流月最旺时兑现
- "天干管上半年、地支管下半年"为粗糙近似，准确法是干支各自在对应流月当令时兑现

## 四、藏干深层作用

### 三层架构

| 层次 | 机制 | 判断要点 |
|------|------|---------|
| **透干发用** | 藏干透出天干→人格化、事件化 | 透出即"司命"，主动出面 |
| **虚神得用** | 藏干不透→深层隐性力量 | 月令藏多透少，不透者为虚神。虚神得用者多名气/财富 |
| **引动爆发** | 大运/流年刑冲合害→藏干被激活 | 引动后吉则增吉，凶则增凶 |

### 人元司事（月令分值）

月令藏干非一月均权，而是分日轮流当令：
- **司令**：月令本气，为真神
- **司权**：当前值日藏干
- **司命**：透出天干者

三者合一（既司令又司权又司命）= **真神得用**，格局层次最高。

## 五、纳音实战

### 纳音生克链

以年柱纳音为"君"，其余三柱为"臣"：

| 关系 | 含义 | 吉凶 |
|------|------|------|
| 月/日/时纳音**生**年柱纳音 | 祖业受生，先贫后富 | 大吉 |
| 月/日/时纳音**克**年柱纳音 | 根基受损 | 大凶 |
| 年柱纳音**克**月/日/时纳音 | 得财但压力大 | 中平 |
| 年柱纳音**生**月/日/时纳音 | 泄身劳碌 | 中平偏凶 |
| 同类比和 | 同心助力 | 吉 |

### 顺克与逆克

- **顺克**（年→月→日→时依次相克）：富贵之命
- **逆克**（时→日→月→年依次相克）：破败之命，三起三落
- **顺生**（年→月→日→时依次相生）：泄气劳碌
- **逆生**（时→日→月→年依次相生）：大贵之命

### 流年纳音断事

| 流年纳音 vs 年柱纳音 | 吉凶 |
|----------------------|------|
| 流年生年柱 | 大吉 |
| 流年比和年柱 | 吉 |
| 年柱克流年 | 中平 |
| 年柱生流年 | 凶（泄气） |
| 流年克年柱 | 大凶 |

## 六、十二长生实战应用

### 日干在各支的长生状态

日干对照大运/流年地支的十二长生状态，是判断运势能量高低的核心指标：

- **长生/冠带/临官/帝旺** → 能量充足，宜行动
- **衰/病/死/墓/绝** → 能量低迷，宜守不宜攻
- **胎/养** → 酝酿新事物，暗中积累

### 关键应用

- **帝旺 = 禄地**：能量顶峰，也是物极必反点
- **墓库**：旺者传统上可称“库”、衰者可称“墓”，但是否形成可用资源及刑冲作用，需结合透藏、旺衰和整体结构；不以冲/刑单独判定“打开”。
- **绝处逢生**：日干/用神坐绝，但地支有合局解救 → 绝地反击
- **长生逢冲**：喜神长生被冲 = 根基动摇；忌神长生被冲 = 阻其壮大（吉）

## 七、宫位叠象（星宫同参）

### 核心原则

**"星"定人事内容（什么事），"宫"定发生领域（何人何事）。**

| 宫位 | 代表领域 | 常见叠象 |
|------|---------|---------|
| 年柱 | 祖上/幼年/家族 | 财星在年→祖辈经商；印星在年→书香门第 |
| 月柱 | 父母/兄弟/青年/事业 | 官杀在月→父母管教严或事业压力大 |
| 日支 | 配偶/中年/自身 | 财在日支→配偶带财；官在日支→配偶有权威 |
| 时柱 | 子女/晚年/下属 | 食伤在时→子女有才华；印在时→晚年有精神寄托 |

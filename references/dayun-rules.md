# 大运规则详解

## 一、阳年与阴年

天干分阴阳：
- **阳年**：年干为甲、丙、戊、庚、壬
- **阴年**：年干为乙、丁、己、辛、癸

## 二、大运顺逆规则

| 年干 | 性别 | 大运方向 |
|------|------|---------|
| 阳年 | 男 | 顺排 |
| 阳年 | 女 | 逆排 |
| 阴年 | 男 | 逆排 |
| 阴年 | 女 | 顺排 |

口诀：阳男阴女顺排，阴男阳女逆排。

## 三、大运排列方法

以月柱干支为基准，进行顺排或逆排：

### 顺排
从月柱开始，天干和地支各往后推一位，依次排列。

例：月柱为丙寅，顺排大运为：丁卯 → 戊辰 → 己巳 → 庚午 → 辛未 → ...

天干顺推：甲→乙→丙→丁→戊→己→庚→辛→壬→癸→甲（循环）
地支顺推：子→丑→寅→卯→辰→巳→午→未→申→酉→戌→亥→子（循环）

### 逆排
从月柱开始，天干和地支各往前推一位，依次排列。

例：月柱为丙寅，逆排大运为：乙丑 → 甲子 → 癸亥 → 壬戌 → 辛酉 → ...

天干逆推：癸→壬→辛→庚→己→戊→丁→丙→乙→甲→癸（循环）
地支逆推：亥→戌→酉→申→未→午→巳→辰→卯→寅→丑→子→亥（循环）

## 四、起运年龄计算

### 顺排起运年龄
从出生日起，顺数到下一个**节**（注意是"节"而非"气"），计算总天数，除以 3，得数即为起运年龄。

公式：起运年龄 = 出生日到下一个节气天数 ÷ 3

### 逆排起运年龄
从出生日起，逆数到上一个**节**，计算总天数，除以 3，得数即为起运年龄。

公式：起运年龄 = 出生日到上一个节气天数 ÷ 3

### 十二节（用于起运计算）
立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒

注：节与气的区别——每月一节一气，节为月之始，气为月之中。排大运只看"节"。

### 余数处理
- 余 1 天：约 4 个月起运
- 余 2 天：约 8 个月起运
- 余 0 天：整岁起运

四舍五入到最接近的整数岁数。

## 五、大运周期

每步大运管十年。

排列示例（假设 5 岁起运，月柱丙寅，顺排）：
| 大运序 | 年龄范围 | 干支 |
|--------|---------|------|
| 第一步 | 5-14 岁 | 丁卯 |
| 第二步 | 15-24 岁 | 戊辰 |
| 第三步 | 25-34 岁 | 己巳 |
| 第四步 | 35-44 岁 | 庚午 |
| 第五步 | 45-54 岁 | 辛未 |
| 第六步 | 55-64 岁 | 壬申 |
| 第七步 | 65-74 岁 | 癸酉 |
| 第八步 | 75-84 岁 | 甲戌 |

## 六、交运前的小运

小孩未交大运之前（即起运年龄之前），以月柱干支作为大运。

例：如果 5 岁起运，则 0-4 岁这段时间，以月柱的干支来分析运势。

## 七、流年

流年即每一年的天干地支，用来判断当年的运势吉凶。

- 流年干支与原局（四柱）产生的关系（冲、合、刑、害等）影响当年运势
- 流年与大运的关系也很重要：大运为环境，流年为引动
- 大运好、流年差：总体平稳但当年有波折
- 大运差、流年好：总体不利但当年有机遇

## 八、注意事项

1. 大运的交接年份（换运年）通常变动较大，需要特别关注
2. 大运天干管前五年，地支管后五年（此为一家之言，也有主张天干地支共管十年）
3. 大运与原局形成的天合地合、天克地冲等关系需要重点分析
4. 分析大运时要结合原局格局的喜忌，喜神到位则吉，忌神到位则凶

## 九、流年具体事件判断规则

以下规则用于逐年级地识别具体事件类型（桃花、升学、婚恋、事业等）。每条规则给出判定条件和信号强度（★=可能，★★=较可能，★★★=极可能）。满足条件越多、信号越强，事件发生的概率越高。

### 9.1 桃花/感情事件

桃花年指异性缘旺、易发生恋爱、感情波动的年份。

#### 信号等级

| 信号 | 等级 |
|------|------|
| 流年地支为原局桃花星 | ★ |
| 流年地支为红鸾/天喜 | ★ |
| 流年天干为日主之财星（男）或官星（女），且地支合日支 | ★★ |
| 流年地支与桃花星相合（桃花被合动） | ★★ |
| 流年地支与日支（夫妻宫）相合 | ★★ |
| 流年地支合入夫妻宫（桃花合入日支） | ★★★ |
| 红鸾/天喜叠临桃花 | ★★★ |
| 女命流年见正官、男命流年见正财，且与大运/原局无冲克 | ★★★ |
| 流年地支与日支相冲（夫妻宫逢冲） | ★★ （感情波动/分手） |

#### 桃花星查法（以年支或日支查）

| 年支/日支 | 桃花 | 红鸾 | 天喜 |
|-----------|------|------|------|
| 子 | 酉 | 卯 | 酉 |
| 丑 | 午 | 寅 | 申 |
| 寅 | 卯 | 丑 | 未 |
| 卯 | 子 | 子 | 午 |
| 辰 | 酉 | 亥 | 巳 |
| 巳 | 午 | 戌 | 辰 |
| 午 | 卯 | 酉 | 卯 |
| 未 | 子 | 申 | 寅 |
| 申 | 卯 | 未 | 丑 |
| 酉 | 午 | 午 | 子 |
| 戌 | 亥 | 巳 | 亥 |
| 亥 | 子 | 辰 | 戌 |

#### 分析要点
- 已婚者桃花年需注意夫妻宫是否受冲，冲则易有婚姻危机
- 桃花星为喜用神 → 正缘，质量高；为忌神 → 烂桃花，损耗
- 桃花+驿马同现 → 异地恋或旅途邂逅
- 连续两年桃花信号叠加 → 感情持续升温

### 9.2 升学/考试事件

升学、考试、考证、功名的年份。

#### 信号等级

| 信号 | 等级 |
|------|------|
| 流年天干为印星（正印/偏印），印星为喜用 | ★ |
| 流年地支为文昌贵人 | ★ |
| 流年地支为学堂 | ★ |
| 流年印星透干且有根 | ★★ |
| 流年官印相生（官星生印星）且为喜用 | ★★ |
| 大运+流年同时见印星/文昌/学堂 | ★★ |
| 流年印星得力，且文昌星不被冲克 | ★★ |
| 流年官星得位+印星有力，格局清纯 | ★★★ |

#### 文昌贵人查法（以日干查）

| 日干 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
|------|----|----|----|----|----|----|----|----|----|----|
| 文昌 | 巳 | 午 | 申 | 酉 | 申 | 酉 | 亥 | 子 | 寅 | 卯 |

#### 分析要点
- 印星代表学业、文书。印星为喜用的考试运强于为忌
- 官星代表功名、考试结果。官印相生之年最利升学
- 文昌/学堂被冲克 → 考试发挥失常
- 食伤过旺而印制不住 → 贪玩影响学业
- 月柱（17-32岁）大运见印星/文昌 → 青年时期学业整体有利

### 9.3 婚嫁/婚姻事件

结婚、订婚的年份。

#### 信号等级

| 信号 | 等级 |
|------|------|
| 大运已到婚恋阶段（青年大运），流年见配偶星 | ★ |
| 流年红鸾/天喜入命 | ★★ |
| 流年天干为配偶星（女见官、男见财）且合日干 | ★★ |
| 流年地支与日支（夫妻宫）相合（六合/三合） | ★★ |
| 流年桃花合入日支 | ★★ |
| 日支逢合且配偶星得力 | ★★★ |
| 红鸾/天喜+桃花+配偶星三者同现 | ★★★ |
| 流年与日柱天合地合 | ★★★ |

#### 配偶星
- 女命：正官为夫，七杀为偏夫/男友
- 男命：正财为妻，偏财为偏妻/女友

#### 分析要点
- 配偶星出现需看是否为喜用。为喜用则婚姻美满，为忌则婚后多矛盾
- 日支逢合为婚姻信号，逢冲为感情危机信号（已婚者防离婚）
- 大运官杀混杂（女命）或财星混杂（男命）时婚恋选择多但难定
- 孤辰/寡宿在日支或时支 → 晚婚倾向，流年需更强信号才能引动
- 换大运前后（交运年）感情变动概率大

### 9.4 事业/工作变动事件

换工作、升职、创业、事业转折的年份。

#### 信号等级

| 信号 | 等级 |
|------|------|
| 流年驿马星出现 | ★ |
| 流年天干为官星/七杀，为喜用 | ★ |
| 流年地支冲月支（事业宫） | ★ |
| 流年驿马+官星同现 | ★★ |
| 流年官杀与日主有情（合、生） | ★★ |
| 流年与大运发生天克地冲 | ★★ |
| 驿马逢冲（寅申冲/巳亥冲） | ★★ |
| 流年官星+印星相生且为喜用 → 晋升信号 | ★★★ |
| 流年伤官见官 → 离职/与上级冲突 | ★★★ |

#### 驿马查法（以年支或日支查）

| 年支/日支 | 申子辰 | 寅午戌 | 巳酉丑 | 亥卯未 |
|-----------|--------|--------|--------|--------|
| 驿马 | 寅 | 申 | 亥 | 巳 |

#### 分析要点
- 驿马+官星为喜 → 升职或好的跳槽
- 驿马+七杀为忌 → 被迫换工作或工作环境恶劣
- 伤官见官之年 → 注意与领导关系，易有冲突或离职
- 月柱（事业宫）逢冲 → 工作环境/单位变动
- 大运换运前后（交运年）→ 事业方向常有转折

### 9.5 财运事件

财运高峰期、破财风险的年份。

#### 信号等级

| 信号 | 等级 |
|------|------|
| 流年天干为财星（正财/偏财） | ★ |
| 财星为喜用且在地支有根 | ★★ |
| 食伤生财：流年食神/伤官生助财星 | ★★ |
| 财星合入日干（财来合我） | ★★ |
| 偏财透干+驿马 → 远方得财或投资机会 | ★★ |
| 流年财星+天乙贵人同现 → 贵人带财 | ★★★ |
| 劫财/比肩夺财 → 破财信号 | ★★★（负面） |
| 财星被冲克 → 财务损失 | ★★ （负面） |

#### 分析要点
- 正财为稳定收入，偏财为投资/意外之财
- 流年比劫夺财 → 破财、被借钱、投资亏损。喜官杀制比劫护财
- 财星为忌神时，财年反主压力（财多身弱）
- 食伤生财年 → 靠技能/创意赚钱，适合开展副业

### 9.6 健康注意事项

需要关注健康的年份。

#### 信号等级

| 信号 | 等级 |
|------|------|
| 流年天干为日主之七杀，杀旺无制 | ★ |
| 流年地支冲日支（自身宫位逢冲） | ★ |
| 岁运并临（大运与流年干支相同） | ★★ |
| 流年与日柱天克地冲 | ★★ |
| 日主受克严重（宫位、干支多处受克） | ★★ |
| 羊刃逢冲 | ★★★ |
| 岁运并临+日柱受冲 | ★★★ |

#### 分析要点
- 岁运并临 → "岁运并临，不死自己死他人"之说，需结合十神判断是自身还是六亲
- 羊刃逢冲 → 防意外血光、手术
- 日柱受冲 → 自身或配偶健康波动
- 健康预警年建议以医学检查为准，命理分析仅为提醒

### 9.8 使用说明

分析近 N 年事件时，按以下步骤操作：

1. **逐年扫描**：对目标年份，逐一检查上述七类事件的信号
2. **信号叠加**：同一事件类型满足多条规则 → 信号增强
3. **优先级**：信号强度高（★★★）的年份优先列出
4. **交叉事件**：同年有多个类型的事件信号，综合分析（如驿马+官星+财星 → 因工作调动带来财运）
5. **大运背景**：先判断当前大运的总体基调（吉/凶/平），再分析流年细节
6. **适度推理**：命理分析仅供文化参考，不应对具体事件做出绝对断言
